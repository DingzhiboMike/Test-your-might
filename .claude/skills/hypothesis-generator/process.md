# Генератор: предмет «процесс»

Читается, только если в ТЗ `ПРЕДМЕТ: процесс`.

Если в ТЗ `ПРЕДМЕТ: процесс`, гипотезы — о том, как команда или система делает работу, а не о клиентах. Клиентские рамки (push / pull / inertia / anxiety, точка слома, носитель в роли, слои M1–M13) здесь не работают: «субъект — владелец процесса» и «inertia — привычная структура» — признак того, что шаблон не тот. Вместо Шага 3 — форма ниже; гигиена A и B — как обычно, по слотам «Узел, Изменение, Эффект, Механизм».

```
### Г-N — <кратко>
- **Узел:**          где в процессе меняем: постановка / сбор данных / поиск / синтез / проверка / планирование / сдача / координация
- **Изменение:**     что именно меняем в узле
- **Эффект:**        что улучшится и в чём измеряется — качество выводов, цена, скорость, надёжность или удобство человека
- **Ось:**           качество / цена / скорость / надёжность / удобство
- **Механизм:**      почему это сработает; при разведке поля — из направления карты
- **Стоит на направлении:** НП-k / вне карты: почему — только если была разведка поля
- **Цена внедрения:** что нужно: правка инструкции, скрипт, лишний вызов, время человека
- **Риск регресса:** что может стать хуже — какая проверка, свойство или качество пострадает
- **Опровергнет:**   что должно случиться на одинаковых входах, чтобы гипотеза оказалась неверна
- **Контроль:**      [контрольная] — если вне вектора консультанта
- **Опора:**         ступень внешней опоры по `web-protocol.md`, п. 1б (обзор / сравнение / кейс / практик / вендор) с «…» [F-id], или «нет»
```

- **Разнообразие — по узлам и осям.** Не больше половины гипотез в одном узле; хотя бы две разные оси. Контрольная гипотеза удобна в другом узле или с противоположной ставкой: «упростить», «убрать шаг», «оставить как есть».
- **Опора — не утверждение команды.** Описание процесса из `context/` — то, что проверяется (R-016), а не опора механизма. Механизм держит внешний источник или наблюдение из прошлых прогонов с фрагментом.
- **Эффект — на одинаковых входах.** Формулируй так, чтобы его можно было увидеть парным сравнением на сохранённых кейсах (`evals/`): «на тех же кейсах доля X меньше при расходе не выше Y», а не «станет лучше».
- Строку РАСПРЕДЕЛЕНИЕ ПО РАМКАМ заменяет РАСПРЕДЕЛЕНИЕ ПО УЗЛАМ И ОСЯМ.

Форму проверяет `check_process.py` после шага.
