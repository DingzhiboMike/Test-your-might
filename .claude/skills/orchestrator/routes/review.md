# Маршрут: разбор

Тип выхода «разбор». Финиш — после консультанта (ядро, «Шаг 1 — консультант»).

### Чек-лист готовности: разбор

**Разбор**
- названо хотя бы одно слабое место как разрыв логики, а не категория
- есть самое рискованное допущение
- есть вектор: одно-два направления без конкретных решений
- есть вопрос, который проверить первым
