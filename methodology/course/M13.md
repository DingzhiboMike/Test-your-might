# M13. Рост: план встретился с реальностью

Зачем: читать расхождение плана с реальностью как данные, находить слой, где сломалось, и растить выручку из тех, кто уже пришёл.

## Первая версия плана — первая гипотеза
Три штатные причины расхождения:
- клиент говорит одно, делает другое — между намерением и действием разрыв;
- рынок изменился между планом и запуском — для этого ведётся журнал сигналов (M4);
- внутренние ограничения проявились позже — одновременно обычно живут два-три рычага из пяти.
План — живой документ: корректируется по данным, без пересборки с нуля. Реакция — не искать виноватых, а смотреть, где тяга, и двигать ресурсы туда.

## Три сигнала
Не реагировать на первый симптом: сначала определить сигнал.
**Сигнал 1. Работает, но медленнее плана.** Стратегия почти никогда не виновата. Проверить потолок канала (упёрся — добавить второй, сообщение не трогать) и время (SEO, собственные медиа разгоняются месяцами).
**Сигнал 2. Не работает совсем.** Диагностика по слоям — строго сверху вниз:
| Слой | Что сломано | Как проверить |
| --- | --- | --- |
| 1. сегмент (M1–M2) | разговор не с тем человеком | сравнить пришедших с профилем сегмента |
| 2. позиционирование (M5) | клиент тот, но не узнаёт свою ситуацию | тест коридора: 3–5 людей из сегмента, «не уверен, что это для нас» — мимо |
| 3. сообщение (M6–M7) | позиция верная, формулировки не цепляют | нормальные открытия и ноль кликов — мимо содержание; мало открытий — мимо тема |
| 4. канал (M8) | сообщение не доезжает | конверсия каналов при одном и том же сообщении |
| 5. продукт | клиент пришёл, но не получил ценность | где отваливаются в онбординге и активации |
Начать снизу («переделаем лендинг») — потратить недели и выяснить, что говорил не с тем сегментом.
**Сигнал 3. Рост оттуда, где не ждали.** Сегмент или канал вне плана даёт больше запланированного. Самый ценный и самый игнорируемый сигнал: разобрать, почему пришли, — кандидат в новый рычаг.

## Петли роста: воронка кончается, петля — нет
Клиент использует продукт → получает ценность → создаёт сигнал → сигнал приводит следующего. Воронка масштабируется бюджетом, петля — продуктом.
| Петля | Механика | Условие |
| --- | --- | --- |
| виральная | результат виден другим, другие приходят | результат выходит наружу: отчёты, шеринг, сообщество |
| контентная | опыт клиента становится кейсом, отзывом, постом | налаженный сбор: интервью через ~3 месяца после оплаты |
| data-driven | продукт копит данные, данные становятся аргументом | данные, которые клиент ценит |
Выбор: виден ли результат снаружи — виральная; копит ли продукт ценные данные — data-driven; контентная работает почти у всех.

## Expansion: клиент, который уже достал карту
Расширение существующего клиента в разы дешевле нового: позиционирование объяснять поздно, он уже выбрал.
| Механизм | Триггер | Сообщение |
| --- | --- | --- |
| upsell | упёрся в лимит тарифа | проблему не объяснять — показать следующий шаг внутри продукта |
| cross-sell | решил одну задачу, видит смежную | «задача X решена, следующая логичная — Y» |
| advocacy | высокая активность и измеримый результат | кейс → реферальная программа → выступление |
Сигналы в данных: близко к лимиту — upsell; один модуль ежедневно, второй не открыт — cross-sell; высокая активность с результатом — advocacy; резкое падение активности — риск оттока. Нет аналитики — раз в месяц вручную с customer success.

## Lifecycle: шесть состояний одного клиента
Триал / первый контакт → активация → привычка → expansion → advocacy → риск оттока. У каждого состояния своя коммуникация и свой показатель; задача — видеть, где сколько клиентов и где теряется больше всего. Дерево целей — вертикаль (цель → метрика → рычаг), lifecycle — горизонталь: один клиент со временем проходит через все направления.

## Ритм пересмотра
| Частота | Что смотрим | Решения |
| --- | --- | --- |
| еженедельно | leading-метрики | никаких; резкое изменение — диагностика по слоям |
| ежемесячно | рычаги, каналы, журнал сигналов | тактические: бюджет, формулировки |
| ежеквартально | дерево целей, обратный счёт, сигнал 3 | добавить или убить рычаг, сместить направление |
| раз в полгода–год | позиционирование, сегменты, конкуренты | стратегические, Tier 1 |
