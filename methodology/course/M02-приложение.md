# Приложение к M2. Количественная проверка глубины

Когда: карта соответствий собрана, в ней есть хотя бы один разрыв каждого типа. Раньше нельзя — без интервью варианты ответов будут неправильными.

## Инструмент 1: вынужденный выбор
- Список пейнов **языком клиента** из интервью, 6–8 пунктов.
- Задание: «выберите 3 самых важных из 8». Не шкала: на шкале все ставят 7–8.
- 30–50 ответов достаточно для устойчивого паттерна.
- Позиционирование строится на пунктах, которые выбирает большинство.
- Проверка формулировки: если её можно поставить в рекламный баннер без изменений — она слишком абстрактная, это язык продукта.

## Инструмент 2: данные, которые уже есть
- поведение в продукте: какими функциями пользуются, какие открыли и забыли;
- обращения в поддержку за квартал, разнесённые по пейнам из интервью;
- опрос при отмене подписки.
Главная задача из интервью не подтверждается поведением (например, ключевую функцию не включили) — это разрыв между обещанием и реальностью, вопрос продукту.

## Развилка
☐ приоритеты из опроса совпали с интервью — канвас подтверждён
☐ не совпали — вернуться в левую часть и переформулировать пейны
