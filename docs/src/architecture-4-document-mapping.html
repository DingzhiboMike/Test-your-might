Зелёная рамка — делает скрипт, а не модель: очистка, числа и срезы, проверка карты, надёжность клеток, проверка цепочки.
Лёгкая модель описывает и тегирует документы, выбирает из списка кандидатов, цитирует дословно; «что важно» не решает: важность считает скрипт по формуле из ТЗ.
Карта документов не зависит от задачи и кэшируется по хэшу файла; повторные задачи по тем же файлам её не пересчитывают.
Человек подтверждает рамки продукта (что в продукте есть и чего нет) и определения групп: их не выводят из документов.
Модель предмета — матрица «группа × признак»: в клетке значение дословно, группа источника, n, тип, свежесть; пустые клетки остаются пустыми.
Углубление — полное чтение документа по запросу модели предмета, консультанта, генератора или проверки; лимит по тиру.
Каждый документ читается целиком не более двух раз: при картографии и в углублении; остальные шаги работают с картой и моделью.
Качество картографии измеряет аудит: слепое сравнение сильной моделью на выборке, пороги записаны до проверки.
