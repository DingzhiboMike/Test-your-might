# Схемы

`architecture.html` — источник схем: роли, семь маршрутов, пример прогона, правила и принципы. Открывается в браузере локально (GitHub показывает её как текст). Три PNG в этой папке — снимки трёх схем из неё: тёмная тема, двойной масштаб, 1904 px в ширину. После изменений в системе сначала правится HTML, потом с него заново снимаются PNG.

Актуальное описание системы — `AGENTS.md` в корне; контракты скиллов — `.claude/skills/orchestrator/registry.md`.
