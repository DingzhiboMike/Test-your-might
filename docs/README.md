# Схемы

Три PNG в этой папке — схемы системы: роли, хранилища, маршрут и контур эксперимента; маршруты по семи типам выхода; пример прогона (валидация идеи). Тёмная тема, двойной масштаб, 1904 px в ширину. Исходника в репозитории нет: после изменений в системе схемы перерисовываются заново, а старые файлы заменяются.

Актуальное описание системы — `AGENTS.md` в корне; контракты скиллов — `.claude/skills/orchestrator/registry.md`.
