# Замечания к системе

Журнал правок системы: что поправить в скиллах, реестре и правилах и что поправлено. Пишет только человек, когда правит систему, — словами о системе, без названий задач, продуктов, партнёров, сегментов, чисел и формулировок из задач. Замечания из сдач оркестратор пишет в локальный `system-notes.local.md` (в git не попадает); сюда их переносят обезличенными.

Формат записи:

```
## <дата> — <задача>
- [<скилл или файл>] Что заметил, на каком шаге, чем помешало. Что предлагаешь поправить.
```

Когда замечание исправлено — отметь это отдельным блоком:

```
## <дата> — разобрано
- Что поправлено и в каких файлах.
```
