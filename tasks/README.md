# Задачи

Эту папку заполняет система. На каждую задачу диспетчер создаёт отдельную папку: ТЗ, лог оркестратора, результаты каждого шага.

Руками сюда кладётся только одно: результаты живой проверки — в `tasks/<задача>/results/`. После этого напиши диспетчеру — он сам поймёт, к какой задаче они относятся.

Содержимое этой папки в git не попадает — см. `.gitignore`.
