# Контекст проекта

Сюда — всё, что ты знаешь о продукте и клиентах, до запуска задачи. Диспетчер читает эту папку первым и показывает в ТЗ, что прочитал и чего не хватает.

Что класть:
- описание продукта: что это, для кого, цена, формат
- интервью с клиентами — транскрипты или заметки
- выгрузки: клиентская база по сегментам, биллинг, воронка, причины отказов и отмен
- обращения в поддержку, отзывы, переписки
- прошлые исследования и результаты проверок

Формат любой: markdown, текст, таблицы. Ничего нет — не страшно: система пойдёт в открытые источники и честно скажет, чего не хватает.

`from-tasks/` — сюда система сама складывает материалы исследований и результаты живых проверок из прошлых задач. Руками туда ничего класть не нужно.

Содержимое этой папки в git не попадает — см. `.gitignore`.
